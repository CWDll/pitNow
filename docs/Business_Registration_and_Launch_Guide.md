# PitNow 사업자 등록 및 유료 출시 준비 가이드

- 작성일: 2026-07-31
- 문서 상태: 유료 출시 전 실행안
- 대상: PitNow 운영자, 공동 검토자

> 이 문서는 PitNow의 현재 사업 모델을 기준으로 작성한 실무 체크리스트다.
> 법률·세무 자문을 대체하지 않으며, 실제 신고와 계약 전에는 관할 기관,
> PG사, 세무사 또는 변호사에게 최종 확인한다.

## 1. 현재 사업 모델 정의

PitNow는 다음 구조를 기본안으로 한다.

- 사용자는 PitNow에서 정비소 정보와 예약 가능 시간을 확인한다.
- 사용자는 SELF 베이 이용 또는 SHOP 정비 패키지를 예약하고 결제한다.
- 실제 베이·시설·정비 서비스 제공자는 입점 정비소다.
- PitNow는 예약, 결제 연결, 운영 기록, 고객 문의와 분쟁 접수를 제공한다.
- PitNow의 수익은 정비소가 지급하는 중개수수료다.

따라서 사업상 기본 지위는 다음과 같이 정리한다.

| 참여자 | 기본 역할 |
| --- | --- |
| 사용자 | 정비 서비스를 예약·이용하는 소비자 |
| 정비소 | 실제 서비스 판매자이자 제공자 |
| PitNow | 통신판매중개 플랫폼 및 예약 시스템 운영자 |

서비스와 약관에는 아래 취지를 명확히 표시한다.

> PitNow는 통신판매중개자로서 예약 및 결제를 중개하며, 실제 정비 서비스의
> 제공 주체는 각 정비소입니다. 다만 PitNow의 예약·결제 시스템 오류와
> PitNow가 직접 제공하는 서비스에 관한 책임까지 배제되지는 않습니다.

## 2. 지금 사업자등록이 필요한가

현재처럼 Toss 테스트 키로 개발·비공개 QA만 진행하고 실제 매출이 없다면
즉시 사업자등록을 마쳐야 하는 단계는 아니다.

다만 다음 중 하나를 시작하기 전에는 사업자등록을 완료한다.

- Toss 라이브 가맹점 계약
- 실제 고객의 유료 예약 접수
- 정비소에서 중개수수료 수취
- 공개적인 유료 서비스 출시

국세청은 사업 개시 전 사업자등록을 허용하며, 사업을 시작한 경우 원칙적으로
사업 개시일부터 20일 이내 등록하도록 안내한다.

- 국세청 사업자등록 안내:
  https://s.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7776&mi=2443
- 정부24 사업자등록 신청:
  https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=12100000072&HighCtgCD=A09002&tp_seq=

## 3. 권장 사업자 형태

초기에는 1인 개인사업자로 시작하는 것을 권장한다.

현재 PitNow는 다음 조건에 해당한다.

- 1인 개발·운영
- 의정부 지역 중심의 소규모 파일럿
- 투자자·공동창업자·직원이 아직 없음
- 초기 매출과 입점 정비소 수가 불확실함

법인 전환은 다음 상황에서 다시 검토한다.

- 공동창업자 또는 투자자 참여
- 직원 채용
- 여러 지역으로 확장
- 정산 금액과 사고 책임 규모 증가
- 개인 자산과 사업 책임을 분리할 필요 증가

개인사업자는 사업상 책임이 대표자 개인에게 직접 연결될 수 있으므로,
소규모 운영이라도 파트너 계약과 보험 확인을 생략하지 않는다.

## 4. 유료 출시 준비 순서

### Step 1. 사업 모델과 결제 구조 확정

아래 항목을 문장으로 확정한다.

- 정비소가 실제 서비스 판매자다.
- PitNow는 통신판매중개자다.
- 사용자 결제금의 귀속 주체
- PG 수수료 부담 주체
- PitNow 중개수수료율과 부가가치세 처리
- 취소·환불·노쇼·차지백 부담 주체
- 정비소 정산 주기

세부 운영안은 `docs/Payment_Settlement_and_Partner_Onboarding.md`를 따른다.

### Step 2. 사업장 주소와 상호 결정

결정할 항목:

- 상호: 예시 `PitNow` 또는 한글 상호 병기
- 대표자
- 사업장 주소
- 연락처와 운영 이메일
- 서비스 도메인

자택을 사업장 주소로 사용할 경우 확인할 내용:

- 임대차계약상 사업자등록 가능 여부
- 임대인 동의 필요 여부
- 사업자 정보 화면과 통신판매업 정보에서 주소가 공개될 가능성

주소 노출이 부담되면 적법하게 사업자등록이 가능한 별도 사업장 또는
비상주 사무실을 검토한다.

### Step 3. 업종코드와 과세유형 확인

국세청 `126` 또는 세무사에게 아래와 같이 설명한다.

> 온라인에서 정비소의 SELF 베이와 정비 패키지 예약·결제를 중개하고,
> 정비소에서 거래액 기준 중개수수료를 받는 1인 플랫폼입니다.
> 정비 서비스의 실제 판매자와 제공자는 입점 정비소입니다.

확인할 질문:

1. 주업종·부업종 코드는 무엇으로 등록해야 하는가?
2. 전자상거래 소매중개 또는 정보서비스 관련 업종을 함께 등록해야 하는가?
3. 일반과세자와 간이과세자 중 어떤 형태가 적합한가?
4. 정비소에 발행할 중개수수료 세금계산서 처리는 어떻게 하는가?
5. PG 정산 구조별로 PitNow 매출을 수수료만 인식하려면 어떤 증빙이 필요한가?

과세유형과 업종코드는 임의로 확정하지 말고 실제 결제·정산 구조를 설명한 뒤
확인한다.

### Step 4. 개인사업자 등록

신청 경로:

- 홈택스 온라인 신청
- 관할 세무서 방문

일반적인 준비물:

- 사업자등록 신청서
- 대표자 신분 확인 자료
- 임대 사업장인 경우 임대차계약서
- 인허가 대상 업종을 직접 영위하는 경우 관련 허가·등록 자료

예상:

- 신청 수수료: 없음
- 처리 기간: 통상 2~3영업일
- 추가 현장 확인이나 서류 보완이 있으면 더 소요될 수 있음

PitNow는 정비소를 중개하는 사업자이고 직접 자동차정비업을 영위하지 않는
구조를 목표로 하지만, 최종 업종과 인허가 필요 여부는 관할 기관에 확인한다.

### Step 5. 사업용 금융·회계 환경 준비

- 사업용 계좌 개설
- 사업용 카드 분리
- 회계 프로그램 또는 장부 방식 결정
- 세금계산서 발행 환경 준비
- 정비소별 거래·환불·수수료 정산서 양식 준비
- 세무사 이용 여부 결정

개인 생활비와 사업 정산금을 같은 계좌에서 관리하지 않는다.

### Step 6. Toss Payments 라이브 계약 문의

테스트 키 연동 완료는 기술 검증일 뿐, 라이브 가맹점과 정산 구조가 확정된
것은 아니다.

사업자등록 전에는 구조 상담을 진행하고, 사업자등록 후 실제 계약·심사를
진행한다.

- Toss Payments 고객센터: 1544-7772
- 계약 문의: support@tosspayments.com
- PG 개념 및 계약 문의:
  https://docs.tosspayments.com/resources/glossary/pg

문의할 핵심:

- 정비소가 판매자인 플랫폼 구조
- 정비소별 MID 또는 하위 가맹점 구성 가능 여부
- 카드 매출전표에 표시되는 판매자
- 지급대행 적용 조건과 비용
- 취소·부분취소·차지백 주체
- 개인사업자 플랫폼 계약 가능 여부

상세 문의문은 결제·정산 문서에 수록한다.

### Step 7. 통신판매업 신고

사업자등록과 통신판매업 신고는 별개다.

일반적인 순서:

1. 사업자등록 완료
2. PG·구매안전서비스 관련 서류 확인
3. 정부24 또는 관할 시·군·구청에서 통신판매업 신고
4. 등록면허세 확인·납부
5. 통신판매업 신고번호를 서비스에 표시

- 정부24 통신판매업 신고:
  https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=11300000006&HighCtgCD=A09006&tp_seq=01
- 공정거래위원회 안내:
  https://www.ftc.go.kr/www/bizContents.do?key=253
- 의정부시 등록면허세 안내:
  https://ui4u.go.kr/portal/contents.do?mId=0204110300

일반적인 예상:

- 신고 신청 수수료: 없음
- 처리 기간: 통상 약 3일
- 별도 등록면허세가 최초 신고 및 매년 발생할 수 있음

PitNow는 이용일 전에 결제하는 예약 구조이므로 선지급 거래 관련 서류가
필요한지 관할 부서와 Toss에 확인한다. 카드결제는 구매안전서비스 의무의
예외가 될 수 있으나 결제수단과 계약 구조에 따라 확인이 필요하다.

### Step 8. 필수 정책과 계약 준비

공개 서비스용 문서:

- 서비스 이용약관
- 개인정보처리방침
- 위치정보 이용 관련 고지 또는 약관 필요 여부 검토
- 취소·환불·노쇼 정책
- 통신판매중개자 고지
- 분쟁 처리 기준
- 공개 사진·리뷰 신고 및 삭제 정책

파트너용 문서:

- 파트너 입점 계약
- 수수료·정산 부속합의서
- 개인정보 처리 관련 약정
- 취소·환불·차지백 부담 기준
- 사고·보험·시설 책임 기준
- 사진·상호·로고 사용 동의

인터넷의 다른 서비스 약관을 그대로 복사하지 않는다. PitNow의 실제 기능,
책임 분담, 결제 흐름에 맞춰 초안을 만든 뒤 유료 출시 전 법률 검토를 받는다.

### Step 9. 정비업 관련 행정 확인

입점 예정 정비소의 설명만으로 허용 업무를 판단하지 않는다.

관할 자동차관리사업 담당 부서에 아래 모델을 설명하고 확인한다.

- 사용자가 베이·리프트·장비를 빌려 직접 작업하는 SELF
- 정비사가 유료로 수행하는 정비사 작업 확인
- 정비사가 처음부터 끝까지 수행하는 SHOP 패키지
- 플랫폼이 예약·결제를 중개하는 구조

확인할 내용:

- 정비소의 자동차관리사업 등록 범위 안에서 가능한 작업
- SELF 시설 대여 시 필요한 안전·시설 조건
- 정비사 작업 확인의 허용 범위와 표현
- SHOP 패키지별 허용 정비 범위
- 사고 발생 시 책임과 보험 요건

자동차관리사업 등록 관련 법령:
https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030707521

### Step 10. 파트너 실사 및 계약

첫 정비소는 실제 방문해 시설과 서류를 함께 확인한다.

필수 확인:

- 사업자등록증
- 자동차관리사업 등록증
- 등록된 사업장 주소와 실제 영업장 일치
- 대표자 및 운영 담당자
- 사업자 명의 정산계좌
- 시설·영업배상책임보험
- 리프트 규격과 안전점검 상태
- 허용 차종·중량
- 운영시간과 베이 수
- 제공 SELF 작업과 SHOP 패키지
- 가격과 취소·환불 조건

계약과 서류 확인이 끝난 뒤 담당자별 Partner-admin 계정을 초대한다.
공용 ID와 비밀번호를 여러 명에게 전달하지 않는다.

### Step 11. Production 최종 점검

- Vercel Production 환경변수 검토
- Toss 라이브 키 전환
- 실결제 소액 승인·취소·환불 검증
- 정비소 판매자 정보 표시 확인
- 수수료 정산서 생성 확인
- 개인정보·약관·취소정책 링크 확인
- 고객센터와 분쟁 접수 채널 확인
- DB 백업·감사 로그·장애 대응 확인

실결제 검증은 정비소 및 Toss와 합의한 계정·금액으로 최소 범위에서 수행한다.

## 5. 분쟁 처리 기준 초안

| 유형 | 1차 책임·처리 |
| --- | --- |
| 중복결제, 예약 반영 실패, 시스템 오류 | PitNow |
| 정비소의 예약 거절·노쇼 | PitNow 접수 후 정비소와 조정 |
| 정비 품질, 작업 결과, 시설 사고 | 정비소 1차 책임, PitNow 접수·증거 전달 |
| 사용자 노쇼·규정 위반·시설 파손 | 사전 공개된 정책과 증거에 따라 처리 |
| 취소·환불 | 공개 정책과 파트너 계약에 따라 처리 |

운영 기준:

- 접수 채널: 앱, 이메일, 전화
- 증거: 예약·결제 로그, 체크인·체크아웃 사진, 상태 로그, 파트너 메모
- 접수 후 3영업일 이내 진행 상황 안내
- 접수 후 10영업일 이내 처리 결과 또는 처리 계획 안내
- 책임 판단이 어려우면 보험사·관할기관·분쟁조정기관으로 이관

통신판매중개자는 소비자가 쉽게 알 수 있도록 자신이 거래 당사자가 아니라는
사실을 미리 고지하고, 판매자의 신원정보를 청약 전에 제공해야 한다.

- 전자상거래법 통신판매중개자 의무:
  https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1022341869

## 6. 서비스 내 법적 고지 UI 권장안

모바일 서비스라고 해서 사업자 정보를 숨기거나 `/mypage`에만 두는 것은
권장하지 않는다.

다음 두 곳을 함께 제공한다.

### A. 공통 `법적 고지` 라우트

권장 경로: `/legal`

포함할 항목:

- PitNow 사업자 정보
- 통신판매업 신고정보
- 고객센터 정보
- 통신판매중개자 고지
- 이용약관
- 개인정보처리방침
- 취소·환불·노쇼 정책
- 분쟁 처리 기준
- 정비소 판매자 정보 확인 방법
- 오픈소스 라이선스 또는 앱 정보

긴 문서를 한 화면에 모두 펼치기보다 목록에서 각 상세 문서로 이동하게 한다.

권장 세부 경로:

- `/legal/terms`
- `/legal/privacy`
- `/legal/refund`
- `/legal/disputes`
- `/legal/intermediary`

### B. `/mypage` 하단의 축약 사업자 정보

예시:

```text
PitNow | 대표 홍길동
사업자등록번호 000-00-00000
통신판매업 신고번호 제2026-의정부-0000호
주소 경기도 의정부시 ...
고객센터 help@pitnow.example

이용약관 · 개인정보처리방침 · 취소/환불정책 · 사업자정보
```

사업자등록 전에는 가짜 번호나 임시 번호를 넣지 않는다. 개발·QA 환경에서는
`사업자 정보 준비 중`으로 표시하거나 해당 섹션을 비공개로 둔다.

### C. 결제 직전 판매자 정보

공통 법적 고지와 별개로 예약·결제 화면에는 해당 정비소의 판매자 정보를
청약 전에 확인할 수 있어야 한다.

- 정비소 상호
- 대표자
- 사업자등록번호
- 주소
- 전화번호
- 서비스 제공 주체
- 적용되는 취소·환불 기준
- PitNow가 통신판매중개자라는 고지

모바일 초기 화면은 공간 제약이 있어 상세 링크를 사용할 수 있지만,
소비자가 쉽게 찾고 확인할 수 있어야 한다.

전자상거래법 시행규칙은 휴대전화 등 출력에 제한이 있는 기기의 표시 방법을
별도로 두고 있다.

- 전자상거래법 시행규칙:
  https://www.law.go.kr/LSW/lsPdfPrint.do?ancYnChk=0&bylChaChk=N&efGubun=Y&efYd=20231212&joAllCheck=Y&joEfOutPutYn=on&lsiSeq=256905&mokChaChk=N
