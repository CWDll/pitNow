# Self 작업 확인 및 안전 콘텐츠

이 문서는 Self Service 작업 카드, 정비사 작업 확인 결과, 안전교육 화면에서
사용하는 운영 문구의 기준이다.

## 공통 원칙

- 정비사 작업 확인은 사용자가 예약한 작업의 정해진 항목만 확인한다.
- 차량 전체 안전성, 향후 고장, 운행 가능 여부를 보증하지 않는다.
- 예약하지 않은 작업이나 추가 분해는 확인이 제한될 수 있다.
- `안전 보증`, `완벽 검수`, `출고 승인`, `PASS`, `FAIL` 표현을 사용하지 않는다.
- 결과는 `특이사항 없음`, `이상 발견`, `확인 불가`로 기록한다.

## 작업별 확인 항목

### 엔진오일 교환

1. 드레인볼트 체결 상태
2. 오일필터 체결 상태
3. 엔진오일량
4. 외부 누유 여부
5. 관련 경고등 점등 여부

### 브레이크 패드 교환

1. 브레이크 패드 장착 상태
2. 캘리퍼 체결 상태
3. 휠 체결 상태
4. 브레이크 페달 작동 상태
5. 육안상 누유 또는 이상 여부

### 타이어 로테이션

1. 타이어 장착 위치
2. 휠너트 체결 상태
3. 타이어 공기압
4. 육안상 장착 이상 여부

### 에어필터 교환

1. 필터 장착 방향
2. 에어클리너 커버 체결 상태

### 와이퍼 블레이드 교체

1. 와이퍼 체결 상태
2. 와이퍼 작동 여부
3. 유리 간섭 여부

## 확인 불가 사유 예시

- 예약하지 않은 작업까지 수행함
- 이미 조립되어 핵심 부위를 확인할 수 없음
- 작업 범위가 예약 내용보다 넓음
- 장비 또는 현장 조건상 합리적으로 확인하기 어려움

## 재확인과 별도 작업

- 이상 발견 항목은 예약 이용 시간 안에서 1회 재확인을 포함한다.
- 추가 확인은 정비소 운영 상황에 따라 현장에서 협의한다.
- 정비사가 직접 수정하는 작업은 정비사 작업 확인에 포함되지 않는다.
- 직접 수정과 추가 비용은 정비소와 사용자가 현장에서 별도 협의한다.

## 공통 안전교육

첫 Self 이용 전에 다음 내용을 공통교육으로 1회 확인한다.

1. 리프트와 잭 사용 전 차량 지지점 및 잠금 상태 확인
2. 회전체, 고온부, 배터리와 전기장치 접근 전 주의
3. 보안경, 장갑, 작업복 등 보호장비 착용
4. 화기와 인화성 물질 반입 금지
5. 폐유, 오염물, 교체 부품의 지정 장소 처리
6. 이상 상황 발생 시 즉시 작업 중단 및 현장 관리자 호출

공통교육은 `common-self-safety-v1`으로 시작하며 내용이 크게 변경되면 새
버전을 발행한다.

## 작업별 안전카드

### 엔진오일 교환

- 엔진과 배기계가 충분히 식은 뒤 작업한다.
- 차량을 리프트 또는 잭스탠드로 안전하게 지지한다.
- 폐유가 피부나 바닥에 닿지 않도록 회수 용기를 사용한다.
- 제조사 지정 오일 규격과 용량은 사용자가 직접 확인한다.

### 브레이크 패드 교환

- 제동장치 작업은 중급 작업이며 이해가 부족하면 진행하지 않는다.
- 차량과 휠을 안정적으로 지지한 뒤 작업한다.
- 브레이크 호스를 비틀거나 캘리퍼 무게를 호스에 걸지 않는다.
- 작업 후 저속 구간에서 제동 상태를 확인한다.

### 타이어 로테이션

- 차량을 평탄한 곳에서 지지하고 휠 분리 순서를 확인한다.
- 휠너트는 차량 제조사 지정 순서와 토크를 따른다.
- 공기압은 차량 표기 기준을 사용한다.

### 에어필터 교환

- 시동을 끄고 엔진룸의 고온부에 주의한다.
- 필터 방향과 커버 고정클립 위치를 분리 전에 확인한다.
- 흡기구 안으로 이물질이 들어가지 않도록 한다.

### 와이퍼 블레이드 교체

- 와이퍼 암이 유리로 튕기지 않도록 손으로 지지한다.
- 규격과 좌우 위치를 확인한 뒤 장착한다.
- 장착 후 저속 작동으로 간섭과 이탈 여부를 확인한다.

## 필수 영상 계획

- 공통 안전교육: 2~3분, 첫 Self 이용 전 필수
- 브레이크 패드 교환: 60~90초, 작업별 필수 영상 후보
- 리프트 사용: 공통교육 내 실제 장비 촬영 필수
- 나머지 작업: 초기에는 안전카드로 제공하고 사고 데이터와 운영 피드백에 따라
  필수 영상을 추가한다.

AI는 대본, 스토리보드, 자막, 위험 상황 애니메이션 제작에 사용할 수 있다.
실제 체결 방향, 토크값, 리프트 포인트와 장비 조작은 AI 영상만으로 안내하지
않고 전문가 검토와 실제 촬영 자료를 사용한다.
